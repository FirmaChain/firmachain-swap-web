# Firmachain Swap Web

## Environment

-   Node v20
-   React 18.3
-   Redux
-   Styled-components

---

## Initial setup

```bash
nvm use
yarn install
```

---

## Development

### Local Development

```bash
yarn run dev 	# Uses .env.dev
```
---

## Code Quality

### Linting

```bash
yarn lint 	# Check code style
```

### Formatting

```bash
yarn format 		# Check formatting
yarn format:fix 	# Fix formatting issues
```
